# standards/ — 公司标准挂载点(扩展点)

本仓库是**开源基础**,只含通用内容:能力层(MCP)、品牌知识层(`brands/<brand>/skills/`)、
通用方法论(根 `skills/`)。**公司标准一律不进本仓库**——它们住在独立的上层标准库(私有),
使用时"叠加"到这里:

- 把上层库的 `<company>/` 目录**复制**或**符号链接**到本目录;
- 知识层手册按 `standards/<company>/<framework>/` 的既有引用读取公司框架
  (命名体系、UDT 分类、报警机制、MES 约定等以挂载的标准为准);
- 本目录内容已被 `.gitignore` 忽略(`standards/*`,仅保留本 README)——挂载什么都不会被提交。
