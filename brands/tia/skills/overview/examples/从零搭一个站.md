# 示例:从零搭一个站(端到端)

> 何时用:想完整走一遍"建项目 → 组态 → 编程 → 复用 → 编译"全链路。串起全部 4 个 skill。

前置:`tia_connect` + `--mode ReadWrite`。**一会话一个项目**(开新前先 close)。

## 链路

### 1. 建项目(见 [连接与项目管理](../../connect-project/SKILL.md))
`tia_project_create` → 新项目(如 MyProject)。

### 2. 硬件组态(见 [硬件组态](../../hardware-config/SKILL.md))
- `tia_catalog_search "6ES7 511"` → 拿 CPU typeIdentifier。
- `tia_device_add` CPU 1511C-1 PN(`6ES7 511-1CK00-0AB0/V2.9`)→ 站名 `PLC_1`。
- `tia_module_add` ×2:DI16(`6ES7 521-1BH00`)、DQ16(`6ES7 522-1BH00`)。
- `tia_network_configure`:IP / 掩码 / 子网 / IO-System。
- `tia_hardware_read` 核对。

### 3. 写数据 + 逻辑(见 [写程序](../../write-program/SKILL.md))
- `tia_tag_create` ×N:如 Start `%I0.0`、Stop `%I0.1`、Motor `%Q0.0`。
- `tia_udt_import`:如 `UDT_Motor`。
- `tia_block_generate_from_source`:喂 SCL `FUNCTION MotorControl`(自保持逻辑)。
- 在 OB1(Main)里调用该 FC(LAD `Call`,见 [SimaticML速查](../../_reference/simaticml-reference.md))。

### 4. 复用库模块(见 [复用已有模块](../../reuse-library/SKILL.md),可选)
- `tia_library_open` 全局库 `.al21` → `tia_mastercopy_list` → `tia_block_create_from_copy` 实例化标准设备块。

### 5. 编译 + 保存
- `tia_project_compile`(All)→ Software **0/0** 且 Hardware **0/0**。
- `tia_project_save`。

## 注意

`tia_project_compile` 在 **headless 新建(spawn)** 项目上是安全的(GUI 崩溃问题只在 attach 模式重型操作时出现)。
